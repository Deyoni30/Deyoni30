## 🚀 Projets phare

### 🔰 Sentinel - Détection de fraude Mobile Money
Système de détection automatique des fraudes pour transactions Orange Money / MTN MoMo, construit pour le hackathon **IBM Bob 2.0 (lablab.ai)**.

- Scoring de risque calibré  sur **6,36M transactions réelles** (dataset PaySim)
- **98% de rappel** sur les fraudes. **100% de précision** au score maximal
- Backend Django REST Framework : upload CSV, scoring temps réel, alertes filtrables
- Explications en langage naturel générées par IA pour analystes non-techniques
- Interface de démo avec upload glisser-déposer et visualisation temps réel

🔗 [Code source](https://github.com/Deyoni30/IBM-IDE)

**Stack :** Python - Django - DRF - pandas - Goq API - Sqlite - Tailwind CSS

### 📃 Assistant Commercial IA pour Freelances
Application web intelligente qui aide les freelances à générer des devis professionnels en 2-3 minutes au lieu de 30.

- **IA intégrée** : analyse de la demande client, détecte le type de projet, génère une estimation à la devise désiré
- Generation PDF professionnelle avec signature électronique, cachet, QR Code (Playwright + HTML/CSS)
- Conversion automatique de devises (FCFA -> EUR, USD, CNY...) via API Frankfurter
- Traduction multilingue automatique du devis via IA
- Authentication JWT, APIREST complète

**Stack :** Python - Django - DRF - PostgreSQL -GROQ API - Playwright - JWT
